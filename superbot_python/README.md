# سوپر ربات مگاپروژه سه‌پلتفرمه (Telegram, Bale, Rubika)
## فاز ۱: معماری یکپارچه، دیتابیس، آداپتورها و هسته مدیریت

این پروژه یک معماری شیءگرا و مقیاس‌پذیر بر پایه **Adapter Pattern** برای اجرای همزمان یک ربات روی سه پیام‌رسان **تلگرام (Telegram)**، **بله (Bale)** و **روبیکا (Rubika)** است.

---

### ۱. معماری و دیاگرام جریان داده (System Flow)

```text

       (api.telegram.org)      (tapi.bale.ai)       (botapi.rubika.ir)
               │                      │                      │
               ▼                      ▼                      ▼
    ┌─────────────────────────────────────────────────────────────┐
    │          HTTP Webhook Server (server.py / port 8080)        │
    └──────────────────────────────┬──────────────────────────────┘
                                   │
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │        Unified Update Parser (core/update_parser.py)        │
    │  - Normalizes updates to UnifiedUpdate, UnifiedMessage, etc.│
    └──────────────────────────────┬──────────────────────────────┘
                                   │
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │         Finite State Machine (core/state_machine.py)        │
    │        Checks if user/admin is in interactive state         │
    └──────────────┬───────────────────────────────┬──────────────┘
                   │                               │
       (Admin Callback / State)        (User Command / Module Menu)
                   ▼                               ▼
    ┌─────────────────────────────┐ ┌─────────────────────────────┐
    │     AdminPanelHandler       │ │       MainMenuHandler       │
    │  - Broadcast to all users   │ │  - /start & Profile         │
    │  - Force Join Management    │ │  - Force Join Verification  │
    │  - User Ban / Points Grant  │ │  - Referral Link & Rewards  │
    │  - Maintenance Toggle       │ │  - 5-Module Inline Submenus │
    └──────────────┬──────────────┘ └──────────────┬──────────────┘
                   │                               │
                   └───────────────┬───────────────┘
                                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │            Unified Sender (core/unified_sender.py)          │
    │     Routes calls to TelegramAdapter, BaleAdapter, Rubika    │
    └──────────────────────────────┬──────────────────────────────┘
                                   │
               ┌───────────────────┼───────────────────┐
               ▼                   ▼                   ▼
      [Telegram Adapter]     [Bale Adapter]     [Rubika Adapter]
```

### ۲. ساختار پوشه‌ها و ماژول‌ها

├── server.py                  # سرور وب‌هوک و توزیع‌کننده رویدادها (Event Dispatcher)
├── database/
│   ├── __init__.py

├── core/

│   ├── unified_models.py      # کلاس‌های داده استاندارد (UnifiedUser, UnifiedMessage, ...)
│   ├── update_parser.py       # نرمال‌ساز وب‌هوک‌های دریافتی از هر ۳ پیام‌رسان
│   ├── unified_sender.py      # لایه ارسال متمرکز خروجی به تفکیک پلتفرم کاربر
│   ├── state_machine.py       # موتور مدیریت وضعیت کاربر (FSM) ذخیره‌شونده در دیتابیس
│   └── http_client.py         # کلاینت HTTP آسنکرون اختصاصی بدون وابستگی خارجی
├── adapters/
│   ├── __init__.py
│   ├── base_adapter.py        # کلاس والد انتزاعی رابط پیام‌رسان‌ها
│   ├── telegram_adapter.py    # آداپتور رسمی تلگرام (Telegram Bot API)
│   ├── bale_adapter.py        # آداپتور پیام‌رسان بله (Bale Bot API)
│   └── rubika_adapter.py      # آداپتور پیام‌رسان روبیکا (Rubika Bot API)
├── services/
│   ├── __init__.py
│   ├── force_join.py          # سرویس قفل کانال‌ها و بررسی عضویت اجباری
│   └── referral_service.py    # سیستم زیرمجموعه‌گیری بین‌پلتفرمی و پاداش سکه
├── keyboards/
│   ├── __init__.py
│   └── inline_menus.py        # سازنده دکمه‌های شیشه‌ای با دکمه بازگشت در تمام صفحات
└── handlers/
    ├── __init__.py
    ├── main_menu.py           # هندلر منوی اصلی، ساب‌منوهای ۵ ماژول و تیکت پشتیبانی
    └── admin_panel.py         # پنل ادمین (آمار، ارسال همگانی، کانال‌ها، بن، امتیاز)

### ۳. جداول دیتابیس طراحی شده در `database.py`

1. **`users`**: ذخیره یکپارچه کاربران تمام پلتفرم‌ها (`platform`, `platform_user_id`, `points`, `diamonds`, `role`, `is_vip`, `is_banned`, `referrer_id`, ...)
2. **`user_states`**: نگهداری وضعیت FSM هر کاربر با دیتای JSON به صورت پایدار.
3. **`force_join_channels`**: لیست کانال‌های جوین اجباری با تفکیک پلتفرم یا سراسری (`all`).
4. **`referrals`**: ثبت تراکنش‌های معرفی کاربر، پاداش‌های پرداخت‌شده و جلوگیری از تقلب.
5. **`transactions`**: دفتر کل (Ledger) افزایش یا کسر سکه و الماس برای حسابرسی مالی.
6. **`admin_logs`**: لاگ کامل تمام فعالیت‌های ادمین‌ها (بن، ارسال همگانی، تغییر تنظیمات).
7. **`support_tickets`**: سیستم تیکت و پیام ناشناس به همراه قابلیت پاسخ‌دهی مستقیم ادمین.
8. **`daily_rewards`**: سیستم پاداش و جایزه ورود روزانه با محدودیت ۲۴ ساعته.
9. **`bot_settings`**: تنظیمات سراسری پویا (حالت تعمیرات، متن خوش‌آمدگویی و فعال/غیرفعال بودن جوین اجباری).

### ۴. نحوه اجرا و تنظیم وب‌هوک‌ها

```bash
# اجرای سرور وب‌هوک
cd superbot_python
python3 run.py
```

آدرس‌های وب‌هوک برای تنظیم در سرور:
- تلگرام: `POST https://yourdomain.com/webhook/telegram`
- بله: `POST https://yourdomain.com/webhook/bale`
- روبیکا: `POST https://yourdomain.com/webhook/rubika`

### ۵. فاز ۲: هوش مصنوعی، ویژن و دانلودر رسانه (AI & Media)
- **ماژول هوش مصنوعی:** اتصال به مدل‌های GPT-4o, DeepSeek, Grok, Groq Llama-3.3, Blackbox AI.
- **تولید و ویرایش تصویر:** ساخت عکس متنی (Dall-E, Fast-Creat)، تبدیل چهره به انیمه و استایل استودیو جیبلی (Ghibli)، افزایش کیفیت عکس (Enhance)، لوگوساز با ۱۴۰ استایل و ۸۰ افکت.
- **استخراج متن (OCR):** استخراج متون فارسی و انگلیسی از تصاویر.
- **دانلودر رسانه و شبکه‌های اجتماعی:**
  - اینستاگرام (پست، استوری، ریلز) و آنالیز پروفایل پیج.
  - یوتیوب، اسپاتیفای و رادیوجوان (جستجو و دانلود مستقیم MP3/MP4).
  - روبیکا و تیک‌تاک (دانلود پست و ویدیو).
  - شناسایی هوشمند موزیک (Shazam) و استخراج صوت MP3 از فایل‌های ویدیو.

### ۶. فاز ۳: ابزارهای کاربردی، کامپایلر، کریپتو و آپلودر دائمی (Utilities)
- **قیمت لحظه‌ای ارزهای دیجیتال و طلا:** استعلام زنده از KuCoin, Binance, Bybit و Nobitex با تبدیل خودکار به تومان.
- **اسکرین‌شات وب‌سایت:** ثبت تصویر تمام‌صفحه از آدرس سایت‌ها.
- **کامپایلر آنلاین کد:** پشتیبانی از زبان‌های Python, PHP, JavaScript, C++, Go, Java, Rust و...
- **کوتاه‌کننده لینک چندسرویسه:** فست‌کریت، TinyURL و is.gd.
- **دانشنامه ویکی‌پدیا:** جستجوی هوشمند به همراه تصویر شاخص و چکیده فارسی.
- **مزاحم‌یاب و نام‌شناس (Numberbook):** شناسایی نام و اپراتور شماره تلفن‌های ایرانی.
- **نتایج زنده فوتبال و جدول لیگ‌ها:** لیگ برتر ایران و لیگ‌های معتبر اروپایی.
- **کانفیگ VPN روزانه:** دریافت کانفیگ‌های تست‌شده V2Ray/Vmess.
- **آپلودر دائمی فایل با دیپ‌لینک (Deep-Link Uploader):** آپلود عکس، ویدیو، صوت و اسناد و تولید لینک اختصاصی دریافت خودکار (مانند ).

### ۷. فاز ۴: شبیه‌ساز زندگی و شهر (Life RP & Underworld)
- **کارت شهروندی و علائم حیاتی:** سن، انرژی، سلامتی، شادی، استرس، گرسنگی، خواب و سطح هوش.
- **بازار کار و ۱۱ شغل تخصصی:** کارگر، فروشنده، راننده، آشپز، معلم، پرستار، مهندس، برنامه‌نویس، پزشک، مدیر و سرمایه‌گذار. شیفت‌های کاری با مصرف انرژی، افزایش تجربه (XP) و واریز دستمزد به کیف پول.
- **املاک و مستغلات با درآمد دوره‌ای:** زمین کوچک، آپارتمان مسکونی، ویلای لوکس، مغازه تجاری و کارخانه صنعتی با قابلیت برداشت خودکار سود انباشته اجاره.
- **بانک مرکزی و اقتصاد شهری:** افتتاح حساب سپرده، واریز و برداشت از خودپرداز، اخذ وام فوری بر اساس لول، بازپرداخت اقساط با ۱۰٪ سود، و انتقال کارت به کارت مستقیم بین شهروندان.
- **بیمارستان و اورژانس:** ویزیت پزشک، بازیابی ۱۰۰٪ سلامتی و انرژی و به صفر رساندن استرس.
- **دانشگاه و تحصیلات عالی:** افزایش سطح هوش (Intelligence) برای دستیابی به مشاغل رده‌بالا.
- **دنیای زیرزمینی و سرقت‌های سازمان‌یافته:** جیب‌بری در مترو، دستبرد به طلافروشی و هک بانک مرکزی شهر با ریسک تعقیب و گریز پلیس، جریمه نقدی، بازداشت و ثبت سوءپیشینه.
- **دادگاه و وثیقه آزادی (Bail):** تعیین مدت زمان حبس در زندان و امکان پرداخت وثیقه نقدی برای آزادی زودهنگام.
- **امور خانواده و ازدواج:** خواستگاری، تعیین مهریه و ثبت رسمی ازدواج.
- **شورای شهر و شهرداری گروه‌ها:** تعیین شهردار، بودجه خزانه شهر و اهدای کمک‌های مالی شهروندان جهت ارتقای رتبه توسعه شهر.
- **رتبه‌بندی ثروتمندان شهر (Forbes RP):** نمایش ۱۰ شهروند ثروتمند بر اساس دارایی نقد و بانکی.
